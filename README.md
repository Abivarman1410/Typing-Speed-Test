# TypeMaster Pro

A typing speed test app built with React, TypeScript, Vite, shadcn/ui, and Tailwind CSS.

## Getting Started

```sh
npm install
npm run dev
```

## Features

- Typing speed test with WPM calculation
- Accuracy tracking
- Custom or randomly generated paragraphs
- Light / dark theme toggle

## Tech Stack

- Vite + React + TypeScript
- shadcn/ui
- Tailwind CSS
